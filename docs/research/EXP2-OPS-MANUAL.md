# EXP-2 运行手册（启动 → 清偿窗口 → 盲测 → 分析）

> 配套：EXP-2-PREREG.md（规则）、scripts/exp2-launch-check.js（启动门）、
> scripts/exp2-analyze.js（分析器）。本手册只写操作序列，规则以预注册为准。

## 阶段 0 · 启动（只做一次）

1. 启动门：`node scripts/exp2-launch-check.js` —— 必要项全 ✓ 才继续。
2. 封存分组：登录后 `POST /api/experiments/exp2/assign`（web /exp2 页显示封存状态）。
3. **立即**把返回的 `sealedHash` 与启动时间填进 EXP-2-PREREG.md 附录（git commit 固化）。
4. 从此刻起 7 天为清偿窗口。

## 阶段 1 · 清偿窗口（第 1-7 天）

**眼镜通道（glasses 组）**：戴眼镜正常清偿——debt 模式只显示本通道欠条，
语音 quiz 答对升证据等级。被试不知道每条欠条在哪组（盲法）。

**web 通道（对照）**：打开 `#/exp2` 页，逐条展开阅读，**计满 45 秒**才算暴露
（对齐公平规则）。别在 B 组做 quiz——那是干预污染。

**操盘节奏**：
- 每天：眼镜正常用；web 组欠条当天读完（阅读下限不叠加到"以后"）。
- 每两三天看一次依从性：`GET /api/experiments/exp2/status`
  （关注 `exposed` 与 `readLogs` 增长）。
- 中断处理：漏一天的 web 阅读顺延，但总窗口不超 10 天（超出记录为偏离）。

## 阶段 2 · 保持期（第 8-21 天）

不主动复习实验欠条（两侧同禁）。期间新产生的欠条不进实验（assign 已封存，
天然隔离）。记录任何"实验外接触到实验欠条内容"的事件（预注册剔除规则 2）。

## 阶段 3 · 盲测（第 14-21 天，一次性完成）

1. `#/exp2` 页盲测区：系统随机抽题，两问作答（复述 + 举例）+ 先验熟悉度 1-5。
2. **不看任何材料作答**；一次提交不可回改。
3. 全部条目测完（`remaining: 0`）。
4. 评分：按 E2 标准（独立复述关键概念 ✓ + 本项目具体例子 ✓ 两项全过=passed）。
   评分在 SQLite `experiment-exp2` 的 blindTests[].e2Passed 写入（规则化评分，
   不看通道字段——评分盲）。

## 阶段 4 · 分析（一次性）

```bash
node scripts/exp2-analyze.js
```

- 输出：依从性（分通道暴露/阅读时长）+ 主分析（卡方近似 + p 值）+
  `docs/research/EXP2-analysis-latest.json` 存档。
- **预注册偏离声明**：分析器当前用组间卡方近似，预注册主检验是 McNemar
  配对——结果报告必须带分析器的 note 原文；若配对数据齐备，补 McNemar 精确
  检验后再下结论。
- 贝叶斯因子（BF10）：样本小，用外部工具（JASP/在线计算器）以 2×2 表补算，
  写进报告。

## 阶段 5 · 收尾

- 轮次记录：EXP2-analysis-latest.json 归档（不覆盖，拷贝加轮次后缀）。
- 三轮跑完（预注册计划）做汇总：三轮森林图式汇总 + 个体内一致性讨论。
- 任何中途发现的问题写回本手册的"偏离记录"节（下方），不回改历史。

### 预启动观察（2026-10-13，R32）

装置全就绪后被试 31 轮未启动任何动作（复核 0/33、accept 0/13、
SESSDATA 未配）。方法学含义：

1. **依从性风险具象化**：EXP-2 设计的 7 天清偿窗口假设被试每日参与；
   实际启动摩擦（页面操作、候选判断的认知成本）可能远超预期。
   单被试设计里被试=研究者尚且如此，扩展到外部被试时该风险加倍。
2. **设计应对（拟议，不回改已预注册部分）**：
   - 清偿窗口从"固定 7 天"弹性化解读为"7 个参与日"（预注册偏离，
     启动时在附录声明）；
   - 行动板（/research 页）已是降低摩擦的机制，实测有效果待观察；
   - 若启动延迟持续 >2 周，考虑最小可行启动：先 accept 5 条候选
     形成初始池，边清偿边推池。
3. 该观察本身进入研究报告的"局限"节：装置就绪度 ≠ 被试就绪度，
   二者的落差是闭环学习系统落地的核心阻力之一（与研究纲领 §3.3
   的生态效度威胁呼应）。
