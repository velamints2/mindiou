# RQ1 构念效度量化方案（Cognitive Debt 的测量学验证）

> 目标：把"认知债务构念是否成立"从断言变成可计算的证据。
> 依据：RESEARCH_PROGRAM §2.1/§3.1（构念定义与 E0-E5）、已有数据资产。
> 版本 v0.1 · 2026-10-13。三个效度维度各配可跑的指标与数据源。

## 0. 构念回顾

认知债务 = AI 代劳成果 − 用户已证明可理解/复述/验证/迁移的部分。
操作化刻度：E0（无证据）→ E1（初补偿）→ E2（延迟回忆）→ E3（误概念抵抗）
→ E4（情境迁移）→ E5（真实工作验证）。

测量学上要回答三件事：这个刻度**测的是同一个东西吗**（结构效度）、
**覆盖了构念全域吗**（内容效度）、**能预测它该预测的东西吗**（预测效度）。

## 1. 结构效度（E0-E5 是单向度爬升还是杂烩）

### 1.1 单调性检验
- 命题：证据等级跃升应与清偿行为量呈单调关系（更多 quiz 次数/更长复习间隔
  才能爬到更高等级），且不出现"高级等级行为量反而少"的倒挂。
- 数据：trainingAttempts（2026-10-13 实测 **9 条**，attempt 评估含六维分；
  修正：早稿误记 779——那是测试用例数不是训练尝试数）。
- 指标：Spearman ρ(evidenceLevel, attempts)；分等级的箱线图；倒挂率
  （E_k+1 中位行为量 < E_k 的比例，应接近 0）。

### 1.2 等级间区分度
- 命题：相邻等级间应有可观察的行为差异（否则等级多余）。
- 数据：同上 + quiz 首答正确率（低等级欠条的首答正确率应低于高等级——
  必要难度的体现）。
- 指标：各等级首答正确率均值差 + 95% CI；若相邻等级 CI 重叠 >50%，
  建议合并等级（修订刻度）。

### 1.3 六维掌握画像的内部结构
- 数据：masteryProfiles 六维（概念理解/独立回忆/提示独立性/误概念抵抗/
  迁移/保持）。
- 指标：六维相关性矩阵；若平均 r > 0.8 → 维度冗余（可合并报告）；
  若 r < 0.2 → 六维可能测了不同构念（需分因子）。单被试下用全部欠条
  （n≈200+）做探索性层次聚类。

## 2. 内容效度（gap 覆盖构念全域）

### 2.1 生成器覆盖率
- 命题：候选来源（MCP 捕获 / B 站消化 / fallback）应覆盖构念定义的四个
  组成部分（关键判断/边界条件/验证方法/取舍逻辑），而非偏科。
- 数据：EXP-1 标注完成后，把 25+ 个 gap 按四成分人工归类（一次编码，
  二周后由被试再编码取一致子集，Cohen's κ）。
- 指标：成分分布；某成分 <10% 即覆盖缺口（指导生成器补规则）。

### 2.2 已有结论接入
- R8 审计已给出：模板生成器 27% 有材料锚点（4/15）——内容效度的第一个
  定量事实：fallback 通道对构念全域的覆盖弱于内容特定通道。
- EXP-1 完成后补：真实通道（MCP/B 站）的锚点率对比（预期显著更高，
  即"识别质量按来源分层"成为构念测量的边界条件）。

## 3. 预测效度（欠条预测它该预测的东西）

### 3.1 主预测：欠条未清偿 → 复发
- 命题：一条真实认知债务（real_debt 标注）在被跳过的情况下，后续工作流
  中应"复发"——再次撞到同一 gap（pm_debt_recurrences 表已有机制）。
- 数据：accept 后复发计数与 EXP-1 标签的联合。
- 指标：real_debt vs not_debt 两组的复发率差（Fisher 精确）；这是构念
  的**后果效度**：只有真债务会咬人。

### 3.2 次预测：清偿提升盲测
- EXP-2 的主效应本身就是 RQ1 的预测效度证据：若 E 等级爬升与盲测通过
  独立相关（控制通道后），说明刻度测到了真实的理解增长。
- 指标：logistic 回归 盲测通过 ~ 清偿后等级 + 通道 + 先验熟悉度
  （n≥40 欠条时）。

### 3.3 负控制：无关欠条不应预测
- 命题：not_debt 条目（臆测/泛化）即使"清偿"也不应表现等级-盲测相关。
- 数据：EXP-1 标 not_debt 且被误清偿的条目（若有）作对照组。

## 5. 判定标准（预先声明，防事后合理化）

- 构念**初步成立**：S1 单调 ρ≥0.4 且无系统性倒挂；S3 覆盖四成分各≥10%；
  S4 real vs not 复发率差方向正确（real 更高）。
- 构念**需修订**：任一维给出强反证（如等级与行为量无关、四成分偏科严重、
  复发率反向）→ 触发刻度或生成器修订，修订记录进 DECISIONS。
- 单被试限定：所有结论标注"单被试纵向"，不做人群外推（与纲领 §3.3 一致）。
