## 3. 系统即实验装置

- 识别层：MCP hook 捕获（Claude/Codex 等）+ B 站视频消化 + 降级 fallback
  三通道；幂等指纹防重复导入（实测有效）。
- 清偿层：Even G2 智能眼镜（语音 quiz、六维掌握画像）+ web 复核台。
- 验证层：证据等级 E0-E5、盲测、复发追踪（真债务会复发=后果效度）。
- 工程质量：779 自动化测试（56 文件）全绿；SDK 0.0.16 门测通过；
  眼镜包 learn-coach-0.9.0。
