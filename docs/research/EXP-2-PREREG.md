# EXP-2 预注册：眼镜碎片清偿 vs 列表浏览的保持效果

> 预注册声明：本文件在数据采集开始前写定。实验结束后的分析必须遵循此处的
> 假设、指标与剔除规则；任何偏离须在结果报告中显式声明理由。
> 关联：RESEARCH_PROGRAM.md §4 EXP-2 · RQ3。
> 版本：v1.0 · 注册日期：2026-10-13（先于任何分组数据采集）

## 1. 背景

眼镜端"看欠条"模式提供语音 quiz、手势翻阅、时间码证据回看；web 端欠条列表
提供同样的信息但无主动提取环节。理论上主动提取优于被动重读
[roediger_2006_testing][dunlosky_2013_techniques]。EXP-2 检验该优势在
"AI 工作流产生的真实欠条"上是否成立——这是 MindIOU 核心交互的因果证据。

## 2. 假设

- H1（主假设）：清偿方式为眼镜 quiz（A 组）的欠条，14 天后 E2 盲测通过率
  显著高于 web 列表浏览（B 组）。
- H2（次假设）：A 组的清偿动作完成率（完成 quiz 流程的比例）不低于 B 组
  （打开列表即算）；若 A 完成率显著更低，主假设的解释需考虑依从性差异。
- H3（探索性）：A 组中失败 quiz 后重试的欠条（必要难度被触发），比一次
  通过的欠条在盲测中保持更好。[bjork_1994_desirable]

## 3. 设计

- **设计类型**：被试内，欠条级随机分组（同一人的欠条池随机对半，避免
  被试间混淆；单被试纵向 + 计划复制到 2-3 名用户）。
- **A（干预）**：欠条仅出现在眼镜端 debts 模式，清偿动作为语音 quiz
  （3 题，答对升证据等级）。
- **B（对照）**：欠条仅出现在 web 端欠条列表，可自由阅读（卡片正面+背面），
  无 quiz。为公平，B 组阅读时长下限 = A 组 quiz 中位时长（在读够前不能关）。
- **盲测**：14 天后统一在 web 端出题（题目来源组不可见，E2 标准：独立复述
  关键概念 + 举一个本项目例子），由未参与分组的评审（或规则化评分器）判分。

## 4. 变量与测量

| 变量 | 操作化 |
|-----|--------|
| 自变量 | 清偿通道（glasses_quiz / web_read），欠条级随机 |
| 主因变量 | 盲测通过（E2 判定 0/1） |
| 次因变量 | 清偿完成率；首答正确率；重试次数 |
| 协变量 | 欠条来源（mcp / bilibili / manual）；欠条长度；先验熟悉度（实验前自评 1-5） |

## 5. 样本与时长

- 欠条池：活跃欠条 ≥ 40 条时启动（当前 208 条 legacy 可筛新近条目）。
- 每轮：新欠条进入池 → 随机分组 → 7 天清偿窗口 → 14 天保持 → 盲测。
- 计划 3 轮，预计 N(欠条) ≈ 120。显著性按欠条级检验（配对 χ² / McNemar），
  α=0.05 双尾；因样本可能不足，同时报告贝叶斯因子（BF10）。

## 6. 随机化与盲法

- 分组：欠条入池时按 gapText 的 SHA-1 首位奇偶分组（可复现、不可预测内容）。
- 盲法：被试本人知晓设计存在但不知每条欠条归属；评审/评分器对分组盲。
- 分组表在实验开始前生成并哈希封存（本文件附录，采集开始后只读）。

## 7. 剔除与分析规则（预先固定）

1. 剔除：清偿窗口内两组都未被打开的欠条（无暴露）。
2. 剔除：盲测时被试主动报告"实验外已经掌握"（先验污染）的欠条，两侧同剔。
3. 缺失：盲测未完成按未通过计（保守）。
4. 主要分析：McNemar 检验（欠条级配对）。
5. 探索分析（H3）：组内比较重试 vs 一次通过，Fisher 精确检验，仅描述性
   除非 n≥30。
6. 不进行：任何未在此声明的子组分析不得进入主结论。

## 9. 效度风险与预案

| 风险 | 预案 |
|-----|------|
| 被试=开发者本人，需求效应 | 欠条级随机 + 盲测评分器规则化；复制到第 2 名用户 |
| 两组曝光不等（眼镜随身 vs web 要开） | 完成率作为 H2 并列报告；暴露日志全量记录 |
| 欠条难度不均 | 协变量回归敏感性分析（来源/长度/先验熟悉度） |
