# 被试快速上手：六项动作的逐步操作路径

> 预计总耗时：复核 15 分钟 + accept 5 分钟 + SESSDATA 2 分钟 + 看视频按需。
> 前置：本机服务已启动（`bash scripts/start-mindiou-local.sh start`），
> 浏览器打开 http://127.0.0.1:5180/mindiou/ 并登录 yg@local.mindiou。

## 动作 1 · accept 待定候选（5 分钟，推池最快路径）

1. 左侧导航进 **消化**（或行动板点"accept 待定候选"）。
2. 页面列出候选会话，点开 `B 站视频消化：…光遗传学…`（最新一条）。
3. 每条候选右侧有 **接受** 按钮：你认为"我确实没完全理解这个概念"
   就点接受；觉得无关点忽略。
4. 接受的候选立即变成活跃欠条入池。13 条处理完池子约 4→10+。

## 动作 2 · EXP-1 复核标注（15 分钟，质量闸门）

1. 进 **EXP-1** 复核台（`#/exp1`）。
2. 逐行读 gap 描述，三选一：
   - **real_debt**：我确实在这件事上没完全理解（能想起具体卡壳场景）
   - **not_debt**：泛泛而谈/重复/系统瞎猜
   - **unsure**：拿不准
3. 判断标准就一条：**这条描述能不能对应一次真实的"我没懂"瞬间**。
4. 标完 33 行（A 层 5 组 + B 层逐条）。标注进度在行动板实时可见。

## 动作 3 · 配置 SESSDATA（2 分钟，解锁字幕模式）

1. 进 **消化** 页的设置区（齿轮或 SESSDATA 输入框）。
2. 浏览器登录 B 站 → F12 → Application → Cookies → 复制 `SESSDATA` 值。
3. 粘贴进输入框保存。存储是 AES-256 加密的（落盘零明文，已实测）。
4. 配置后消化从"标题/简介降级"升级为"全字幕"，候选质量档位提升。

## 动作 4 · 看视频推池（按需，凑到 40）

1. 消化页粘贴 B 站视频链接 → 消化。
2. 处理候选（同动作 1）。
3. 建议选你**工作相关**的视频（真欠条才能进 EXP-2）；每视频约 2-3 条。
4. 池到 40 行动板自动翻 GO。
