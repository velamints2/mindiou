# MindIOU Web 视觉升级任务总结

日期：2026-07-27

## 任务目标

在不更换原生 TypeScript + Vite 技术栈、不修改 API 契约和关键产品文案的前提下，把用户端 Web 从占位样式升级为可面向早期用户的产品界面。视觉方向参考 Apple 官网的克制、清晰和高完成度，但保留 MindIOU 自身的“认知债务清算”产品语义。

## 本次完成

- 重建完整 CSS design system：颜色、字号、间距、圆角、阴影、动效、焦点态和响应式断点。
- 增加低对比度点阵、环境光晕和产品页同心圆背景装饰，保持内容优先。
- 落地页升级为强排版首屏、深色痛点叙事区、三步闭环和品牌化底部 CTA。
- 原理页升级为适合长文阅读的编辑式布局，保留费曼口径说明和谨慎状态说明。
- 登录页升级为克制、可信的玻璃卡片入口。
- 输入页强化核心 textarea、隐私提示、步骤预期与三步进度。
- 时间线页增加连续流程轴、步骤层级、标签和明显的困惑输入区。
- 报告页为证据、危险缺口、费曼卡、下一步行动和困惑处理回执建立不同视觉层级。
- 清偿会话页强化问题、来源、回答反馈、固定输入区和最终结果状态。
- 完整覆盖桌面端、平板与手机端布局，并支持 `prefers-reduced-motion`。
- 增加可见的后端连接状态，区分正在连接、已连接与未连接。
- Web 邀请码改为提交到后端换取 HttpOnly Cookie；浏览器不再保存邀请码。
- 增加零依赖的静态服务器与同源 API 代理，并输出可直接启动的前端压缩包。

## 已知边界

- 本任务只修改当前未纳入子项目版本控制的 `web/` 工作区内容，没有处理该子项目中已有的大量删除状态。
- 未使用真实邀请码和在线 AI 服务执行完整报告到清偿的端到端流程；本次验证证明 Web 代码可以构建和启动，不等同于生产 API 或真机验收。
